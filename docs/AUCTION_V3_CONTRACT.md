# Decision Auction V3 交易与验证合同

## 目标

Auction V3 只研究一个可执行问题：D 日收盘后形成信号，T 日开盘集合竞价按冻结的最高限价买入，T+1 日开盘集合竞价退出，并以扣除费用和滑点后的净收益评价模型。

## 时间边界

- 预测只能使用 D 日及以前的数据。
- T 日竞价价、T 日分钟数据和 T+1 数据不能进入 D 日特征。
- 每个 `pred_YYYYMMDD.csv` 是不可变预测快照；普通运行不会覆盖已有日期。
- 模型只使用已具备买入日和退出日真值的成熟样本训练。
- 时间验证采用扩展窗口、两交易日隔离和后续日期样本外测试，禁止随机拆分。

## 价格指令

报告中的 `recommended_max_price` 是前夜挂单可执行的最高竞价买入限价。真实开盘价超过该价格时不成交；低于该价格时仍按真实开盘撮合价核算，不按限价虚增成本。

最高限价来自历史支持范围内的价格网格。成交概率联合估计“市场可成交”和“真实竞价价不高于该限价”，并强制随限价单调不下降。研究边际等于成本后预测收益减去大亏概率的尾部风险惩罚，再乘联合成交概率；价格还必须满足盈利概率、风险概率和成交概率阈值，并且不超过估计涨停价。系统在合格价格中选择风险调整边际最高点；没有合格价格时输出 `REJECT`。

## 保守成交规则

- 停牌或日线缺失：不成交。
- 一字涨停：不成交。
- 竞价成交金额不能支持配置的单票金额：不成交。
- 真实开盘价高于冻结上限：不成交。
- T+1 一字跌停：不假设卖出，顺延至首次可交易开盘价。

## 真值层级

1. `broker_actual`：`data/auction_v3/broker_fills.csv` 中的实际券商成交和费用。
2. `market_proxy`：竞价表和日线开盘价交叉形成的市场真价代理。
3. `pending`：买入日或退出日尚未成熟，不参与收益准确率统计。

模型推荐账记录全部冻结推荐，不能只保留用户实际购买的股票。券商实际账只覆盖真实成交，不删除模型未执行推荐，从而避免人为选择造成验证偏差。

## 晋级门槛

正式 `BUY` 必须同时通过：至少 250 个历史独立交易日、至少 80 个样本外交易日、基础成本和两倍成本下平均收益均为正、区块 Bootstrap 盈利概率不低于 95%、至少 60% 的滚动 20 日窗口盈利，并优于原始 TopN 基线。未通过时只输出 `SHADOW_ONLY`，继续冻结限价和积累真价，但不得实盘。
