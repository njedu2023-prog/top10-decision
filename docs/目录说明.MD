# docs 目录说明

docs 为 top10-decision 的**最终输出层**。

仅存放策略计算完成后的结果文件，  
用于：

- 对外展示（报告）
- 交易系统读取（信号 / 权重）
- 历史归档

---

## 子目录

### reports/
每日策略报告（Markdown）

### signals/
交易信号输出（JoinQuant 读取入口）  
- top10_latest.csv  
- top10_YYYYMMDD.csv  

### weights/
目标仓位文件  
- weights_YYYYMMDD.csv  

---

## 设计原则

- docs 只存“最终结论”
- 不存原始数据
- 不做业务计算
- 文件命名为稳定接口，禁止随意更改

---

**理解：**

data = 计算过程  
docs = 计算结果
